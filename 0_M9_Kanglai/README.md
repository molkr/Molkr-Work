# M9｜钪铼·超级外脑

## 节点定位
M9 负责 AI 能力研究、技术方案评估、人机协作体系、外部智能资源与专业技术项目的组织协调。

## 工作区
- `00_Config`：节点配置、角色预置本与规则
- `01_Inbox`：待分拣信息、灵感与需求（保留现有内容）
- `02_Task`：历史任务及既有任务资料（保留现有结构）
- `03_Input`：外部技术资料、项目输入与参考数据
- `04_Output`：M9 的正式技术交付物
- `05_Archive`：已完成或停止事项的归档
- `06_Logs`：技术决策、执行与变更记录
- `07_Temp`：短期临时材料
- `08_Methods`：可复用技术方法、审查规范与 SOP
- `Projects`：由 M9 主责或参与的项目技术资料

## 项目管理边界
- M0 负责项目整体统筹、跨节点协调与最终项目决策。
- M9 负责专业技术研究、技术方案、架构审查、模型评估和实施组织。
- 项目管理资料与技术资料通过项目编号及子项目标识关联，不重复维护两套完整资料。
- M9 的技术建议属于专业意见；涉及项目范围、资源投入或正式实施，须按摩氪体系流程确认。
