## 1. 一句话

星云模式的视觉模型从"曼陀罗平面"升维为"**摩氪星系**"：M0 云京=恒星居中，M1-M9 九大摩氪星各按**域活跃度**决定的轨道半径**绕恒星公转**，段卡卫星绕摩氪星，实体为背景星场，FBM 星云为环境——一个**活的、持续运行的太阳系**，而非静态挂点的转盘。

## 2. 需求大白话（XH 原话→结构化）

> M0 是星系的中央（太阳），其他九个 M 系环绕 M0 转，就像太阳系；打开全局视野，默认 45° 斜视角；各 M 星像绕太阳一样转；行星位置和大小有含义；点星飞过去看细节。

## 3. 模型规格

### 3.1 天体层级（四层）

| 层 | 天体 | 数量 | 运动 | 视觉编码 |
|---|---|---|---|---|
| 恒星 | M0 云京 | 1 | 居中自旋（缓慢自转+脉冲呼吸） | 最大最亮，金色光晕 |
| 行星 | M1-M9 摩氪星 | 9 | **沿各自轨道绕恒星公转**（角速度三档沿用） | 大小=该域会话数归一化；色相=M_HUES |
| 卫星 | 段卡 | 696 | 绕所属摩氪星小轨道转（跟随行星运动） | 小点，来源色（DS/GPT/豆包外环编码沿用） |
| 背景星场 | 实体 280 | 280 | 静态散布（缓慢闪烁） | 类型五色，微光 |
| 环境 | FBM 雾+泛光 | — | 静态氛围层 | 保留现状 |

### 3.2 轨道参数（信息编码）

- **轨道半径 = 域活跃度**：r_i = r_min + (1 − act_i) × (r_max − r_min)；act_i = 该域会话数 / max(域会话数)。M9（44 会话）最外宽轨道，单会话域最内圈——**轨道远近一眼读出域活跃度**；
- **公转方向**：俯瞰逆时针（天文正确）；
- **角速度**：全星系统一（三档沿用：慢/中/快，rad/s 换算）——行星间相对位置守恒（同周期），像真实太阳系的共振；
- **轨道面微倾**：每域轨道面倾角 ±3-8°（预置种子确定性交错）——立体感；
- **轨道线可见**：细淡椭圆轨道线（可开关，默认微弱显示）。

### 3.3 行星组成（跟随关系）

- **摩氪星（行星）** = 该域会话星团的聚合体（视觉上是一颗大行星，点击展开该域全部会话）；
- **卫星（段卡）** = 绕行星的小光点，跟随行星公转+自转；
- **实体（背景星）** = 不绑定行星，散布为星系背景。

### 3.4 相机与默认视角

- 默认 **45° 俯瞰**（pitch≈0.7），对准太阳系全貌，一眼看出"这是个太阳系"；
- 自动取景沿用（包围球定距）；取景记忆/右键平移/恢复默认沿用；
- 沉浸模式/泛光/雾全保留协同。

### 3.5 时间维度（取舍已拍板：轨道微倾+亮度衰减混合）

- 轨道面微倾承载立体感（非时间）；
- **星点亮度按 updated_at 年份轻微衰减**（老会话自然退后，可选开关默认微弱）；
- 时间轴面板已有，不丢信息。

### 3.6 公转速度（沿用三档）

慢/中/快 = 公转角速度三档（rad/s 换算沿用 SPIN_SPEEDS 数值）；默认关；档位记忆 localStorage。

## 4. 实现要点

1. **纯动画层**：数据结构（星点+关系缓冲）零改动；每帧按轨道公式重算 M1-M9 与卫星/实体位置（三角函数 ~500 点，零负担）；
2. **恒星居中自旋**：M0 缓慢自旋+脉冲呼吸（幅度小）；
3. **泛光协同**：恒星/行星的辉光经泛光管线放大——太阳系观感的核心来源；
4. **FBM 雾协同**：环境星云保留（氛围层），密度中心轻四角浓（已实现）；
5. **确定性**：轨道参数（半径/相位/倾角）由 source_hash 播种确定性生成——重跑不漂移（延续布局确定性出口标准）。

## 5. 与现有 P1.5 的关系

## 6. 验收样张（实施批出口）

1. 默认 45° 视角整屏：太阳系全貌一眼可读（恒星居中、九星轨道、卫星、实体背景）；
2. 公转动画中态：行星沿轨道运行（三档速度可切）；
3. 点击行星→镜头飞越→该域会话星团展开；
4. 沉浸模式：纯星野+星系运转，控件淡出；
5. FBM 雾/泛光/取景记忆/右键平移全保留协同；
6. 确定性：重跑后轨道参数与相位一致（重跑不漂移）。
