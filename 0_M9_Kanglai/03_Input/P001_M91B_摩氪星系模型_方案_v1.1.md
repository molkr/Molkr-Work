### 1.2 轨道与大小公式

- **活跃度** act_i = ln(1 + n_i) / ln(1 + n_max)（n_i=域会话数，log 归一化拉开偏斜分布）；
- **轨道半径** r_i = r_min + act_i × (r_max − r_min)，**相邻不同 act 值轨道 enforce 最小间距 Δr_min**；统一方向=**活跃度越高越靠外**（M9 最外）；
- **行星大小** size_i = max(size_min, k × sqrt(n_i))（面积正比于数量，感知线性）；
- **新近度通道**（半径不再编码规模）：rec_i = 该域最新会话 updated_at 距今天数 → r_i = r_min + norm(rec_i) × span？——**修订：半径编码规模（log 会话数）、大小编码规模（sqrt）、新近度编码行星光晕色温**（新近域偏暖白、久远域偏冷蓝）——三通道三分量不冗余（AC #9 采纳升级版）；
- **种子**：轨道相位/倾角按 `hub:M{n}` 稳定 ID 播种——新会话加入不洗牌已有行星相位（AC #4 采纳）；半径随数据重算（活跃度变了行星换轨道=特性）。

### 1.3 关系层（边）

- **默认隐藏**（全局视图只见天体与轨道线）；选中行星/会话卫星时，与该天体相关的边以弧线显示；
- 未确认语义关联不出现（真实性约束沿用）；已确认关联（未来 B 层）按确认状态显示。

### 1.4 交互（公转中的冲突处理）

- **选中行星/卫星 → 公转暂停**（目标捕获），退出选中恢复；
- 飞行镜头 700ms 期间公转暂停（防目标漂移）；
- 尊重"减少动效"：开关冻结公转+呼吸+漂移；
- 拾取：CPU 屏幕空间投影按**当前帧位置**计算（天体在动，拾取跟随）。

### 1.5 相机与默认视角

- 默认 45° 俯瞰（pitch 0.7），自动取景对准太阳系全貌（含 TBD 带与星冕）；
- 取景记忆/右键平移/恢复默认/沉浸模式/泛光/FBM 雾（休眠）全保留协同。
