# M91B｜记忆星图

## 项目定位
P001 摩氪记忆库下的可视化与智能交互子项目。M9 负责专业技术研究、架构审查、技术方案与后续实施组织；M0 负责项目统筹和最终项目决策。

## 已确认的架构约束
- 运行方式：离线独立模式 + 本地服务模式（双模式）。
- 规模定位：当前规模优先，同时预留百万级扩展能力。
- AI 运行策略：本地 AI + 云端 AI 双引擎。
- AI 写入策略：全部 AI 分析结果先进入审核区，用户确认后才能写入正式记忆元数据。
- 原始照片、原始对话及其他原始资料不得由 AI 直接修改。
- 基础星图浏览与离线运行不依赖云端 AI。

## 当前阶段
V2 技术架构独立审计准备阶段。审计完成后再综合意见、修订方案并提交 M0；本目录不构成开发授权。

## 目录
- `01_Architecture`：V1/V2 架构方案、数据流、模块边界与技术决策。
- `02_Technical_Audit`：审计任务简报、审查输入和检查清单。
- `03_Review_Output`：Claude、Gemini 等模型的独立审查报告及综合复核。
- `04_Implementation`：经确认后才建立的实施计划、代码结构和交付物。

## 审查流程
1. Claude Sonnet 5.5 High 独立主审（执行时核实模型名称与可用思考档位）。
2. 第二模型独立挑战性复审（如安排，先独立阅读原始输入）。
3. ChatGPT 交叉核对证据、处理分歧并修订方案。
4. M9 形成技术审查意见。
5. M0 进行项目层面最终审查；最终决策权归用户。
