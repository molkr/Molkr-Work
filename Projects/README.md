# Projects

本目录用于存放纳入 `MolKr-Work` 协作的项目资料。

## 使用规则

- 每个项目建立独立目录，原则上从 `_Template` 复制结构。
- 项目目录按资料用途组织，不按 AC 或 AG 的身份拆分。
- AC 与 AG 通过项目目录中的文档交接成果、审核意见和任务信息。
- 项目文档优先使用 Markdown（`.md`）。
- 只创建项目实际需要的目录；模板中的目录可按项目情况保留或删减。
- 本仓库主要保存跨 AC/AG 共享的项目资料，不默认存放源代码、缓存、构建产物和大型运行数据。

## 项目目录命名

使用简洁、稳定的英文或拼音名称。项目正式名称和简介写在项目根目录的 `README.md` 中。
