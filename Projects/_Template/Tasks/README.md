# Tasks

存放 AC 与 AG 之间需要明确交接和跟踪的任务资料。

适合放入：
- AC 交给 AG 的任务简报与执行要求
- AG 的阶段性执行反馈
- AC 的审核意见与修改要求
- 待处理任务、阻塞事项及完成确认

## 使用约定

- 一个相对独立的任务原则上使用一份 Markdown 文件。
- 任务文件应说明任务目标、背景、输入资料、交付要求、限制条件和验收标准；不适用的项目可省略。
- 明确任务发起方、执行方、当前状态和更新时间。
- 任务状态建议使用：待处理（Todo）、进行中（In Progress）、待审核（Review）、已完成（Done）、已阻塞（Blocked）。
- 执行方负责更新执行进展和交付结果；审核方负责记录审核意见。
- 任务完成后，可将有长期参考价值的结论归入 PRD、Research、Design、Development 或 Testing；任务过程文件可留存作为协作记录。

建议命名：`YYYY-MM-DD_TaskName.md`。
