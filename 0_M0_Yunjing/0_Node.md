# M0_Yunjing｜云京节点入口

## 节点身份
- 节点编号：M0
- 节点名称：云京
- 节点定位：超级大脑／中央中枢
- 节点性质：摩氪体系元节点
- 主要职责：全局统筹、中枢调度、跨节点协调、规则维护、状态监控与版本演进。
- 最终决策权：用户

## 入口文件
- 专属预置本：[`M0YJ_001_Yunjing_Preset.md`](00_Config/M0YJ_001_Yunjing_Preset.md)
- 项目工作区：[`02_Project/README.md`](02_Project/README.md)

## 目录结构
- `00_Config`：节点档案、预置本、规则
- `01_Inbox`：待分拣的灵感、新需求与移交事项
- `02_Project`：M0 负责统筹的项目及子项目管理资料
- `03_Input`：跨项目参考资料、外部输入与待处理素材
- `04_Output`：M0 形成或汇总的正式交付物
- `05_Archive`：已完成或停止事项的归档资料
- `06_Logs`：重要执行记录、决策记录与变更日志
- `07_Temp`：短期临时文件，处理完成后清理或归档
- `08_Methods`：可复用的方法、规范与 SOP

## 工作原则
1. M0 负责统筹与协调，不替代各 M 节点的专业职责。
2. 灵感、项目、输入资料、输出交付物分别管理；正式记录遵循用户确认规则。
3. 涉及跨节点事项时，明确主责节点与协作节点。
4. 更新文件前先读取现有版本，避免覆盖有效内容。
5. 本节点目录与本地 D 盘节点目录遵循 MK06 目录规则，保持相同相对路径。
6. 项目管理资料由 M0 维护；专业技术设计与实施资料原则上由对应主责节点维护，通过项目编号关联。
