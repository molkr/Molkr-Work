# Ideas

本目录用于存放当前节点产生或负责跟进的灵感卡。

## 使用规则

- 每条灵感独立建立一份 Markdown 文件。
- 灵感卡采用摩氪体系统一的灵感卡结构，记录灵感名称、核心描述、来源背景、关联节点、状态及后续方向。
- 文件名使用简洁英文，多个单词以下划线 `_` 连接；保留节点编号和灵感序号，例如 `M0_001_Idea_Name.md`。
- 灵感默认状态为“待评估”。未经用户确认，不自动转为任务或项目。
- 跨节点灵感应明确主关联节点和次关联节点；原则上归入主关联节点的 `01_Inbox/Ideas/`。
- 用户确认记录后再创建灵感卡；创建后反馈文件路径和链接。

## 目录归属

本目录属于 M0 云京。其他节点使用相同结构时，应在各自节点的 `01_Inbox/Ideas/` 下建立对应灵感卡，不将其他节点的灵感混放在本目录。
