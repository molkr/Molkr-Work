# M91B｜记忆星图

## 子项目定位
P001 摩氪记忆库下的可视化与智能交互子项目。目标是将已整理的记忆数据转化为可探索的星图，并逐步支持检索、关联分析、问答与记忆洞察。

## 当前架构决策
- 运行方式：离线独立模式 + 本地服务模式（双模式）。
- 规模策略：当前数据规模优先，同时预留百万级扩展能力。
- AI 运行策略：本地 AI + 云端 AI 双引擎。
- AI 写入策略：所有 AI 分析结果先进入审核区，经用户确认后才可写入正式记忆元数据。
- 原始照片、原始对话及其他原始资料不得由 AI 直接修改。

## 审查安排
- 主技术审查：Claude Sonnet 5.5（High 思考强度，实际模型名称与可用档位以执行时产品界面为准）。
- 独立挑战性复审：可由另一模型单独完成，避免先看到主审结论。
- 综合复核：ChatGPT 整合证据、处理分歧并形成修订建议。
- 技术组织：M9 钪铼。
- 最终审查与决策：M0 云京；最终决策权仍归用户。
