# P001｜摩氪记忆库

## 项目定位
摩氪记忆库是个人记忆资产的建设项目，目标是对生活侧与 AI 侧记忆资料进行保护、整理、结构化加工、关联与可视化，使记忆能够持续积累并被 AI 检索和调用。

## 项目管理
- 项目编号：P001
- 管理节点：M0 云京
- 专业协作：按子项目职责确定主责 M 节点
- 当前状态：项目持续规划与分阶段建设；各子项目状态以各自说明为准。

## 子项目
- [M91B_Memory_StarMap](02_Subprojects/M91B_Memory_StarMap/README.md)：记忆星图，负责记忆数据的可视化探索与智能交互方案审查。

## 目录约定
- `01_Planning`：项目总体规划、阶段路线与范围管理。
- `02_Subprojects`：子项目入口、职责边界及关联文档。
- `03_Review`：项目级阶段审查、跨子项目评估与决策记录。

## 管理边界
M0 保存项目统筹、审查和决策资料；各专业主责节点保存其技术设计与实施资料。双方通过 P001 及子项目标识关联，不重复复制全部技术资料。
