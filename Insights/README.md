# Insights AI 对话沉淀（AC 必读）

当一段对话产出了有长期价值的结论、方案或分析时（用户说"沉淀一下"，或你判断值得并征得同意），写入这里。当晚拉取到本地知识库，经用户审核后转入正式知识。

1. 一条一个文件，命名：`日期_时间_主题摘要.md`
   示例：`2026-11-12_2200_知识库架构决策.md`
2. 正文结构：
   - `来源：` 对话主题与日期（如"摩氪知识库架构讨论 2026-11-12"）
   - `结论：` 本次对话达成的核心结论/方案（分条列出）
   - `分歧与待定：` 未达成一致或悬而未决的点（如有）
3. 忠实呈现对话结论，**不夹带对话中没有的新观点**；不要加 frontmatter
4. 该通道内容 status 恒为 draft：**用户审核转正后才是正式知识**，不要声称已沉淀完成
5. 被拉取后文件会删除（历史留存在 git 记录中）；写完直接结束
